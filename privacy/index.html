Privacy Policy

Last updated: September 2026

Precept is a collection of personal software projects built and operated by Alex Engel, for Alex Engel's own household use. Precept does not offer any product or service to the public, does not sell data, and does not use data for advertising.

Household Agent Suite

This project runs two narrowly-scoped automation agents, each authorized against a dedicated Google account created specifically for this household's agents (not Alex's or any family member's personal Google account):

  • Scheduler agent — requests the https://www.googleapis.com/auth/calendar scope on the agent's own Google account. It reads and writes events on that dedicated agent calendar only, and reads free/busy availability on calendars that household members have explicitly shared with it (never event details on shared calendars, only free/busy). It is used solely to coordinate this household's scheduling.
  • Mailroom agent — requests the https://www.googleapis.com/auth/gmail.modify scope on the same dedicated agent Google account. It reads messages in that agent inbox and applies labels to them; it never sends, forwards, drafts, or deletes mail, and never opens attachments. It is used solely to triage and organize this household's email.

What is not accessed: neither agent has access to any personal Gmail or Calendar account belonging to Alex or any family member directly — only the separate, dedicated agent account, plus free/busy visibility that household members grant explicitly through their own Google Calendar sharing settings.

How data is stored: OAuth credentials are stored in the macOS Keychain and a per-agent-scoped secrets manager (Infisical), each agent's credentials isolated from every other agent's. Calendar and email content is processed to carry out the automation described above and is not transmitted to any third party, not stored outside this household's own systems, and not used for any purpose beyond what is described here.

Retention and revocation: Data is retained only as long as needed to operate these agents. Access can be revoked at any time by removing this app's access at myaccount.google.com/permissions on the agent's Google account.
